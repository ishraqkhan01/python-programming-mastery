# 🥇 Project 1 — Student Management System

**Difficulty:** Beginner → Basic

The first project is a console-based Student Management System designed to practice basic Python programming and convert a real-world problem into Python logic.

### Current Features

1. Add Student
2. View All Students
3. Search Student
4. Update Student
5. Delete Student
6. View Student Result
7. Exit

### Student Information

- Student ID
- Name
- Age
- Email
- Course
- Semester
- Marks

### Result Calculation

- Total Marks
- Obtained Marks
- Percentage
- Grade
- Pass/Fail Status

### Concepts Practiced

- Variables
- `input()`
- Type casting
- Conditions
- Strings
- Lists
- Dictionaries
- Loops

### Core Programming Pattern

**Find → Check → Modify**

This pattern is used when searching for a student, checking whether the record exists, and then updating or deleting it.

### Future Extensions

The project specification includes additional challenges such as:

- Show Top Student
- Average class marks
- Passed/failed counts
- Highest/lowest marks
- Sort students by marks
- Sort students by name
- Course-wise student count
- More validation
- Persistent file storage

### Main Features

6. Check Balance
7. Transaction History
8. Update Profile

### Main Learning Focus

- Transaction records
- JSON/CSV storage
- `pathlib`

- Exception handling
- Program architecture

### Architecture Challenge

Before coding, decide:

- What data is required?
- How will an account be represented?
- Where will accounts be stored?
- Which functions are needed?
- Where should validation happen?
- Where should files be read and saved?
- How will login state work?
- How will transactions be recorded?
- How will the menu connect everything?
